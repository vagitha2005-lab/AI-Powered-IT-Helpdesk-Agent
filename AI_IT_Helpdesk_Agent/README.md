# AI-Powered IT Helpdesk Agent

AI-powered IT Helpdesk Agent for intelligent troubleshooting of common IT problems.

## Features

- Troubleshooting knowledge base
- RAG-based information retrieval
- Diagnostic tools
- Local AI using Ollama and TinyLlama
- Streamlit web interface

## Technologies

Python, Streamlit, LangChain, Ollama, TinyLlama
